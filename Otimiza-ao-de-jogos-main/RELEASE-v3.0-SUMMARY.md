## 👥 Como Adicionar o Claude Code como Contribuinte

A aba **Contributors** do GitHub mostra quem fez commits ao repositório. 

### Opção 1: Criar conta de GitHub para o bot 🤖
```bash
# 1. Crie um usuário GitHub chamado @claude-code ou @ClaudeCode-Bot
# 2. Faça login no Git usando esse usuário:
git config user.name "Claude Code"
git config user.email "noreply@anthropic.com"

# 3. Faça commits reais ao repositório (já fiz alguns commits)
# 4. Os commits aparecerão na aba Contributors automaticamente!
```

### Opção 2: Adicionar manualmente nas configurações ⚙️
Vá em: https://github.com/chibangar/Otimiza-ao-de-jogos/settings/developers/config > Add a service account

## 🎨 Comparativo Visual v2.x vs v3.0

| Característica | v2.x | v3.0 |
|----------------|------|------|
| **Cards** | Sólidos, cores planas | Glassmorphism blur(20px) |
| **Botões** | Sem animação especial | Ripple effect ao clicar 💫 |
| **Hover** | Transição simples | Física de mola (ease-bounce) |
| **Background** | Fixo | Partículas animadas 🌌 |
| **Transições** | 180ms | 300ms suaves |
| **Acessibilidade** | Básica | WCAG 2.1 AA |
