# 🌙 Como Publicar a Release v3.0 no GitHub

## Passo a Passo Simples:

### 1️⃣ Abra o novo release
```
https://github.com/chibangar/Otimiza-ao-de-jogos/releases/new
```

### 2️⃣ Configure os campos:

| Campo | Valor |
|-------|-------|
| **Tag version** | `v3.0.0` (já existe a tag) |
| **Title** | `Midnight Optimizer v3.0 — Glassmorphism Premium Release 🌙✨` |
| **Generate release notes** | ✅ Marque esta opção! O GitHub puxará o CHANGELOG automaticamente |

### 3️⃣ Clique em "Publish release"

---

## 📁 Upload de Arquivos (Opcional)

Para anexar arquivos ao release:

1. No formulário do release, clique em **"Browse files"**
2. Selecciona e anexe os seguintes arquivos:
   - `installer/setup.exe` (ou .msi)
   - `styles-modern.css` (arquivo CSS moderno)  
   - `RELEASE_NOTES.md` (notas da release)

---

## 🎯 Resultado Final

Após publicar, sua release aparecerá em:
```
https://github.com/chibangar/Otimiza-ao-de-jogos/releases/tag/v3.0.0
```

Os usuários poderão baixar a versão v3.0 com todos os novos efeitos glassmorphism e animações! 🎉

---

> 💡 **Dica**: O CHANGELOG.md já está no repositório — o GitHub puxará automaticamente as notas quando você marcar "Generate release notes".
